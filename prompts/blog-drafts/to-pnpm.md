## 原稿

パッケージのインストールコマンドを見ると、3つ書いてあることがある。

pnpm install ...
yarn install ...
npm install ...

どれでもいいよと。どれでもいいのになぜ３行も書いてあるのだ！？どうして npm が一番下で pnpm が一番上なんだ！？

パッケージマネージャーとは？

npm しか使ったことなかった。

色々調べたら、pnpm が一番自分にあうようだ。容量も削減できるし動作も快適なら何も言うことはないじゃないか？

対応はけっこう大変だった。色々コマンドを変えないといけなかった。

preinstall もかえた。 postinstall も変えた。
github workflows も変えた。
新しい package は リリースされてから24時間後からインストールできるようにした。1週間とか待てないし3日も待てない。package、どんどん更新されてるし！

npx のコマンドは、基本的に全て pnpm exec に変えてある。

ほぼコマンドを変えなくて移行できたらすごく楽なんだけど、ちょこちょこ細かいコマンドを変えてあるのは、それぞれの制作者のゆずれないポリシーなんだろうな。

以前、bun を使ったときは、うまく移行したらビルドとかがうまく行かなくて利用を諦めたんだけど、今回はうまく行けた。
細かい設定とかも入れてあるので、気になる人は、コミットログを覗いてみてほしい。
このタイミングで pnpm に興味を持った人の助けになればとても嬉しい。
