## Discord Nitro のヘッダーがかっこいい

Discord の Nitro（有料プラン）の案内が来ていたのでちらっと見てみたら、そこにグラスモーフィズム（Glassmorphism）の固定ヘッダーがあって「やっぱかっこいいな...」と思ってしまった。

うちにも固定ヘッダーがある。スクロールしたら上から出てくるヘッダー。スティッキーヘッダー。でもこれグラスデザインじゃないよね。だからこれをかっこよくしたくなった。

## グラスモーフィズムって何？

グラスモーフィズム（Glassmorphism）は、背景をぼかして、半透明の背景色を重ねることで、ガラスのような見た目を作るデザインパターンです。最近のモダンな Web サイトでよく見かけるデザインですね。

実は、スティッキーのグラスデザインヘッダーは前にも作ったことがあるけど、今回の Web サイトでは実装してなかったんだよね。なんでだったかなぁ。忘れてただけなんかなぁ。

## どうやって実装した？

グラスモーフィズムを実現するには、主に以下の要素が必要です：

- **背景のぼかし**: `backdrop-blur` という CSS プロパティを使って、背景をぼかします
- **半透明の背景色**: 背景色を少し暗くして、半透明にします
- **影**: ロゴや文字に影をつけて、視認性を高めます
- **境界線**: ヘッダー下部にうすいラインを引いて、境界を明確にします

## 細かい調整がキモ

背景が明るいときに見えにくくならない工夫もした。背景色は**ほんの少しだけ**暗くなるようにして、`bg-slate-900/10` を設定しました。数字の `10` は不透明度が **10%** という意味です。つまりほぼ素通し。

ヘッダーの高さは、パディングを `p-3` にして余白から決めました。

SVG のロゴにも文字にも `drop-shadow` で影をつけた。これで、背景が明るくても見やすくなるはず。

ぼかしは `backdrop-blur` の既定の強さをそのまま使いました。

ぼかしの加減とか、どれぐらい暗くするとか、すごい微妙で難しい。好みも分かれるところだよね。何度も調整して、ようやく「これかな？」という感じになりました。

ヘッダー下部の境界にも、うすーくラインを引いたり工夫してる。`border-b border-white/10` で、白を 10% だけ乗せた線です。これで、ヘッダーとコンテンツの境界が明確になります。

## ロゴのアウトラインがカッコ悪い

ロゴは SVG で作っているんだけど、アウトラインがなんかカッコ悪いな。よし、表示するかしないかは指定できるようにしよう。で、アウトラインはカッコ悪かったので影をつけるようにしたらいい感じにデザインがシャキッとした。

`LogoIcon` コンポーネントに `radius` というプロパティを追加して、アウトラインの表示/非表示を制御できるようにしました。でも、結局アウトラインは使わずに、`drop-shadow` で影をつけることにしました。これで、ロゴがよりシャープに見えるようになりました。

## まだ納得いってない

まだヘッダーデザインは納得がいっていないので、これからもバージョンアップしていくと思う。

デザインって、完璧にしようとするとキリがないんだよね。でも、その「もっと良くしたい」という気持ちが、サイトを成長させていくんだと思います。

## 【追記】3 か月後、ヘッダーを作り直した

……と書いて終わったんですが、本当にバージョンアップしました。

3 か月後の 2026 年 3 月、僕はヘッダーを一から作り直しています。いま同じ場所の設定を見比べると、こうなっていました。

| 項目           | この記事を書いたとき | 作り直したあと         |
| -------------- | -------------------- | ---------------------- |
| 背景の濃さ     | 10%                  | **70%**                |
| 下の境界線     | 白 10%               | **白 5%**              |
| 高さの決め方   | 余白で調整           | **64 ピクセル固定**    |
| ロゴの影       | 既定の影             | **水色に光る影**       |
| 設定の置き場所 | 部品の中に直書き     | **設定ファイルに分離** |

数字がほぼ全部動いてる。しかも**背景と境界線が正反対の方向に動いている**のが自分でも意外でした。

## ガラスは薄いほどかっこいい。薄いほど読めない

一番大きく変わったのが背景の濃さです。 **10% から 70% へ、 7 倍**。

この記事で僕はこう書いていました。「背景が明るいときに見えにくくならない工夫もした。背景色は少しだけ暗くなるようにして」と。

**「少しだけ」が全然足りてなかったんですね。**

グラスモーフィズムって、透ければ透けるほどガラスっぽくてかっこいいんですよ。だから当時の僕は 10% という、ほとんど素通しの値を選んだ。実際かっこよかった。

でも、その下を明るい画像が流れていくと、ヘッダーの文字が背景に溶けるんです。読めない。かっこいいけど読めない。

**素通しのガラス板から、曇りガラスへ。** 70% まで濃くして、ようやく「どんな背景の上を通っても読める」ヘッダーになりました。ぼかしも既定から一段強い `backdrop-blur-md` に上げています。

透過を売りにした表現なのに、実用にするには透過を諦める方向に振るしかなかった。ここが一番学びでした。

## 面は濃く、線は薄く

面白いのが、**境界線は逆に薄くなっている**ことです。白 10% から **5% へ半減**。

ヘッダーが濃くなったぶん、コンテンツとの境目は線を引かなくても分かるようになった。だから線の仕事が減って、そのぶん薄くできた。

これ、ちょうど [横線を 17 箇所消した話](/blog/simplify-ui) と同じ結論なんですよね。あの記事はこの記事の **9 日前**に書いています。区切り線が要らなくなるのは、他の要素がちゃんと区切りを伝えているとき。**面が仕事をすれば、線は引退できる**。

## 結局使わなかったアウトライン

もうひとつ、正直な報告を。

この記事の中で、ロゴに `radius` というプロパティを足して、アウトラインの表示を切り替えられるようにした、と書きました。結局アウトラインは使わず影にした、とも。

**その切り替え機能、今も残っています。そして 9 か月間、一度も 0 以外の値を渡されていません。**

使うかもしれないと思って作った選択肢が、一度も選ばれないまま部品の中に居座り続けている。（消せばいいのに）

## で、いまは納得しているのか

してません。（笑）

でも 3 か月前と違うのは、**なぜこの値なのかを説明できるようになった**ことです。 70% なのは読めるようにするため。 5% なのは面が区切りを担っているから。 64 ピクセル固定なのはページごとに高さが揺れないようにするため。

当時は「何度も調整して、ようやく これかな？」でした。感覚だけで決めていた。いまは理由がある。

デザインが完成しないのは相変わらずですが、**次に触るときの出発点が「好み」から「理由」に変わった**なら、それは前に進んだということでいいと思っています。
