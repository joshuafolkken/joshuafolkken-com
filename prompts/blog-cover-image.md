# 最優先のルール: 画像に文字を入れない

**生成画像の中に文字・数字・記号・ロゴ・透かしを一切描かないこと。** 日本語・英語・その他
どの言語であっても同じです。看板・本の背表紙・画面の中の UI・コードエディタの行など、
「文字が入りそうな面」は、ぼかす・見切れさせる・無地にするなどして文字そのものを避けます。

理由は品質です。生成モデルの描く文字は崩れて読めないものになり、崩れた文字が 1 か所でも
あればカバー画像として使えません。記事のタイトルは、必要ならサイト側で画像の上に重ねます。

# 構図

- 横長のブログカバー（16:9）。上下左右のどこを切っても成立するよう、主題は中央寄りに置く
- 記事タイトルを重ねる余地として、片側に落ち着いた面（空・壁・被写界深度のボケなど）を残す
- 被写体は 1 つか 2 つに絞る。要素を詰め込まない

# 画作り

- 記事の主題を、そのものずばりの図解ではなく **雰囲気と比喩** で表す
- 実写風の写真、またはミニマルで質感のあるイラストのどちらか。中途半端な混在は避ける
- 落ち着いた配色。原色のべた塗りやネオンの多用はしない
- 使い古された「青い回路基板」「浮かぶ 0 と 1」「ロボットの手と人の手」などの陳腐な AI 表現は避ける
- 実在の人物・企業ロゴ・商標・実在製品の外観を描かない
