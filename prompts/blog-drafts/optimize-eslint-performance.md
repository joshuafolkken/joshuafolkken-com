## 原稿

eslint を全ファイル対象に実行すると 30秒。これは明らかに遅い！

ChatGPT に聞いて色々やってみても、早くならない！
Claude に聞いて色々やってみても、早くならない！
Gemini に聞いて色々やっても、やっぱり早くならない！

自分が書いた eslint の定義が多すぎるのか？と思って徐々に消していった。全然改善しない。

最後に残ったのはこれだ！

```js
languageOptions: {
	globals: { ...globals.browser, ...globals.node },
	parserOptions: {
		projectService: true,
		tsconfigRootDir: import.meta.dirname,
	},
},
```

これか、これが悪いのか！ projectService を project: './tsconfig.json' に書き換える。
新しいエラーが出た。エラーはどんどん変化していく。それにも対応してみる。早くなった！これだったのか！

できたと思ったけど、Svelte ファイルを開いてみるとエディターにエラーが表示される。うううう。なかなか辛いぞ！
行くと織物失敗を経験し・・・・ついにできた！どれだけ試行錯誤したことか。

で、なぜこれが projectService: true だと遅いのか？（詳しい解説AIさんよろしく）

純粋な TypeScript 環境ではハマらなかったと思うのだが、ルールを厳しめにしていたり、ごちゃごちゃ書いていたり、Svelte 用の定義があったりとかなり複雑になっていたのも時間がかかってしまった要因の一つだ。
今回はこれをきっかけに、eslint.config.js に直接書いていた 独自のルールも別ファイルに切り出して管理することにした。
また切り出したりしたら動作がおかしくなったり、細かいところで調整が必要だったりと苦労したのだが、この話は今回はしなくてもいいだろう。

結果的に見れが変えたのはほんの数行だ。しかし一週間ぐらい前から悩んでてアレヤコレヤとやってもできなかったので達成感が半端ない。

ESLint は完璧にマスターしたつもりでいたのに全然マスターできてなかった。課題が発生して、それに立ち向かって、解決したときに成長を感じられる。この繰り返しで強くなるしか無い。
